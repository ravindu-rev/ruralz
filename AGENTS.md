# Ruralz agent instructions

Rules for AI coding agents working in this repository. Tooling and the documents cited here win over this file; if they disagree, follow them and fix this file.

Ruralz is an Apache-2.0 API gateway in Go with no feature gating, owned by Revington. Module `github.com/ravindu-rev/ruralz`. The design lives in `docs/` and is the spec; code is at milestone M0 Foundations.

## What exists today (M0)

| Area | State |
|---|---|
| `cmd/ruralzd`, `cmd/ruralz-control`, `cmd/ruralz` | Wiring only: `signal.NotifyContext`, then `<pkg>.Run(ctx, os.Args[1:], os.Stdout, os.Stderr)`, then `os.Exit` |
| `internal/cli` | Real `ruralz version` (`--output text\|json`) and help; nothing else |
| `internal/gateway`, `internal/control` | Stubs that write "... is Planned (M1)" / "Planned (M2)" to stderr and return 2 |
| `internal/buildinfo` | Real: linker-set version, commit, flavor; Go 1.26 floor guard |
| `internal/errcode` | Real registry of `RZ-<AREA>-<NNN>` codes; no error type carries them yet |
| `pkg/config/v1alpha1` | Real Go types for the 10 kinds and 23 Policy types; no loader or validator |
| `api/schema` | Generated authoring and rendered JSON Schema plus `go:embed` accessors |
| `internal/tool/{repocheck,commitcheck,depgate,schemagen}` | Real CI tools |

Not built yet, so never claim or import them: `internal/config`, `internal/filter`, `internal/telemetry`, `internal/pluginhost`, `internal/statestore`, `internal/controlstore`, `internal/controlstream`, `internal/signing`, `internal/console`, `api/proto`, `sdk/`, `console/`, `deploy/`, `test/`, `examples/`, `buf.yaml`, `go.sum`. `go.mod` has no `require` block.

## Commands

The Makefile needs GNU make, bash, git and curl. On Windows install make separately (Git for Windows lacks it) and run it from Git Bash, because PowerShell's `bash` is WSL; without make, run the Go commands below directly. Go comes from the `go.mod` toolchain line (`go1.27.1`) through `GOTOOLCHAIN=auto`. If `go` is not on PATH, say so; do not install it unasked.

| Purpose | Command | Notes |
|---|---|---|
| Stages 1 to 6 as the Makefile runs them | `DCO_RANGE=origin/main..HEAD PR_TITLE='<title>' make hygiene lint generate build test supply-chain` | Without `DCO_RANGE` and `PR_TITLE`, `hygiene` runs only repocheck. CI `pr-fast` also runs the Go 1.26 floor and the CLI tests on macOS and Windows; `pr-title` checks the title |
| Repo checks | `go run ./internal/tool/repocheck` | Stage 1; also runs inside `go test` |
| Commit checks | `go run ./internal/tool/commitcheck dco -range origin/main..HEAD`; `go run ./internal/tool/commitcheck title -title '<title>'` | Stage 1 |
| Lint | `make lint`; `make fmt` rewrites | Needs golangci-lint v2.13.2 in `bin/`; `make tools` has no Windows pin |
| Regenerate schema | `go generate ./pkg/config/v1alpha1` | `make generate` then fails until the regenerated files are staged, by design |
| Build | `go build ./...`; `make build` cross-builds into `dist/` | |
| Test | `CGO_ENABLED=0 go test -shuffle=on ./...` | `make test` first runs `-race`, which needs cgo and a C compiler |
| Go 1.26 floor | `make floor FLOOR_GOTOOLCHAIN=go1.26.8` | Sets `GOEXPERIMENT=jsonv2` |
| Supply chain | `go mod verify`; `go run ./internal/tool/depgate` | `make supply-chain` also installs govulncheck |

## Hard rules (CI fails otherwise)

- **License header** on every hand-written `.go` file, tests included, then a blank line: `// Copyright <creation year> <copyright holder>` (Revington for Revington's work; keep the year when editing) and `// SPDX-License-Identifier: Apache-2.0` (goheader, `.golangci.yml:104-111`). repocheck requires the same header in the first 512 bytes of `.proto`, `.ts`, `.tsx`, `.mts` and `.cts` files. Generated files instead start with `// Code generated by <tool>. DO NOT EDIT.`
- **No-license-check scan.** Every text file under `cmd/ internal/ pkg/ sdk/ console/`, tracked or not, comments and tests included, must not contain the host `revington.co` (any case, so `revington.com` also fails) or the terms `licensekey`, `licensefile`, `licenseserver`, `licensetoken`, `entitlement`, `enterpriseedition`, `enterpriseonly`. Lines are lower-cased and stripped of `-`, `_`, spaces and tabs before matching, so prose such as "license key" fails. `testdata/`, `bin/`, `dist/`, `node_modules/` and dot-directories are skipped (`internal/tool/repocheck/repocheck.go:49-54,255-351`). Exceptions go in `internal/tool/repocheck/nolicensecheck.allow` and need two approvals.
- **Error codes.** Any `RZ-(CFG|RT|UP|AUTH|RL|PLG|AI|CP|STS)-NNN` inside a Go string literal outside `internal/errcode/` must be registered, tests included (`repocheck.go:181-201`). Every registered code must appear in some doc and every doc code must be registered (`internal/errcode/errcode_test.go:79-120`).
- **`cmd/<binary>/`** holds exactly one Go file, `main.go`, with only imports and `func main`: no `const`, `var`, `type` or other funcs (`repocheck.go:139-148,203-225`). Put flags and logic under `internal/`.
- **Imports.** depguard admits only the standard library and this module in all files, tests included, so no testify, go-cmp or other third-party module without a catalog row and a `.golangci.yml` allow entry in the same pull request (`.golangci.yml:22-27`). `pkg/` and `api/schema` (non-test) import only the standard library and `pkg/`. No `import "C"`. Boundaries: `internal/gateway` never imports `internal/control`, `internal/controlstore` or `internal/cli`; `internal/control` and `internal/cli` never import `internal/gateway`; only `internal/tool` imports `internal/tool`.
- **Banned:** `log` (use `log/slog` through `internal/telemetry`, M1), the `plugin` package, Lua runtimes, `valyala/fasthttp`, `github.com/google/cel-go` (use `cel.dev/cel-go`), `golang.org/x/net/http2` `Server` and `Transport`, `fmt.Print*` outside `internal/cli` (write to an `io.Writer`), `init()` (gochecknoinits).
- **Suppressions** name the linter and a reason: `//nolint:gosec // reason` (nolintlint). A gosec suppression in `internal/filter/auth/`, `internal/filter/authz/`, `internal/signing/` or `internal/pluginhost/` also needs a security reviewer.
- **Generated schema.** Never hand-edit `api/schema/ruralz/v1alpha1/*.schema.json`. Change `pkg/config/v1alpha1`, run `go generate ./pkg/config/v1alpha1`, commit both (`TestCommittedSchemaIsCurrent` fails otherwise).
- **Go 1.26 floor.** The code must build and test on Go 1.26 with `GOEXPERIMENT=jsonv2`: no stdlib API newer than Go 1.26.
- **Tests** pass under `-race -shuffle=on` with cgo and again with `CGO_ENABLED=0`; `internal/cli`, `internal/buildinfo` and `pkg/` tests also run on Windows and macOS.
- **Line endings** are LF everywhere (`.gitattributes`).

Review-enforced (no linter checks it): no mutable package-level variables, except sentinel errors, `go:embed` variables, the linker-set `internal/buildinfo` variables, tests and generated code (doc 02, Code conventions).

## Commits and pull requests

- **DCO.** Every non-merge commit carries `Signed-off-by: <author name> <author email>`; the name must equal the commit author exactly (`git commit -s`; repair with `git rebase --signoff main`). A `Co-Authored-By` trailer does not replace it.
- **Title** (checked on the PR title, which squash merge makes the commit subject): `<type>(<scope>)!: <subject>`, matching `^([a-z]+)(?:\(([a-z0-9][a-z0-9-]*)\))?(!)?: (.+)$`; imperative mood, lower-case first word, no trailing period (`internal/tool/commitcheck/commitcheck.go:130-156`).

| Type | Scopes |
|---|---|
| `feat`, `fix`, `perf`, `refactor` | `gateway`, `control`, `cli`, `config`, `filter`, `plugin`, `ai`, `statestore`, `controlstream`, `console`, `sdk`, `api`, `deploy` |
| `test` | The scopes above, `e2e`, `conformance` |
| `docs` | A document slug: file name under `docs/` without numeric prefix and `.md` (`data-plane`, `glossary`, `readme`, `plugin-abi-v1`); never `03-data-plane` |
| `build`, `ci` | `deps`, `tools`, `workflows` (changes to `internal/tool` are `build(tools)`) |
| `chore`, `revert` | Any |

- Types mean: `feat` new behavior, `fix` bug fix, `perf` performance with benchmark evidence (P10), `refactor` no behavior change, `test` tests only, `docs` documentation only, `build`/`ci` build system or workflows, `chore` maintenance. Changes to `AGENTS.md`, `CLAUDE.md` or `.claude/` use `chore:`.
- Omit the scope when a change spans several. There is no `style` type. Breaking change: `!` plus a `BREAKING CHANGE:` footer. Link decisions with `Refs: OQ-<docslug>-<n>` or `Refs: ADR-NNNN`.
- A pull request stays under 400 changed lines excluding generated files (target), and brings its tests, regenerated files and docs. Two approvals are needed for `api/`, `pkg/`, `docs/_meta/`, `go.mod`, `.github/`, `nolicensecheck.allow` and the security-sensitive packages (`scripts/ci-approvals.sh`).

## Naming

Use the names in `docs/_meta/foundation-pack.md` sections 2 (canonical names), 3 (kinds) and 11 (aliases never to write) verbatim: Ruralz Gateway (`ruralzd`), Ruralz Control (`ruralz-control`), Ruralz Console, CLI `ruralz`, Bundle, Revision, Rollout, Node, Cluster, State Store, Control Stream, and the kinds `Route`, `Upstream`, `Policy`, `Plugin`. Never `RuralZ`, `ruralzctl` or `rz`. apiVersion `ruralz/v1alpha1`. Errors `RZ-<AREA>-<NNN>`; env vars `RURALZ_*`; metrics `ruralz_<component>_<name>_<unit>`. Write `OQ-<docslug>-<n>`, never `TODO` or `TBD`.
