# Trademark policy

"Ruralz" and the Ruralz logo are trademarks of Revington ([revington.co](https://revington.co)). Apache-2.0 covers the code and grants no trademark rights ([source](https://www.apache.org/licenses/LICENSE-2.0)), so this policy says how the name and logo may be used. It follows the nominative use model of the Apache Software Foundation trademark policy ([source](https://www.apache.org/foundation/marks/)).

The policy protects one promise: whoever sees the name Ruralz gets the software Revington publishes from [github.com/ravindu-rev/ruralz](https://github.com/ravindu-rev/ruralz), or is told plainly how what they get relates to it. It never limits what Apache-2.0 lets you do with the code: you may run, fork, modify and sell it, and no feature is held back ([ADR-0002](docs/adr/0002-apache-2-license-no-feature-gating.md)).

## Uses that need no permission

| Use | Rule | Example |
|---|---|---|
| Referring to Ruralz | Any truthful reference in writing, talks, courses, documentation, comparisons or social media | "We run Ruralz in production" |
| Unmodified copies | Redistribute an unmodified Ruralz release, or a build of this repository's unmodified source, under the name Ruralz, keeping `LICENSE` and `NOTICE` | A Linux distribution package named `ruralz` |
| Products built on Ruralz | Say "based on Ruralz", "powered by Ruralz" or "for Ruralz" when it is true, as long as your product's own name does not contain Ruralz | "Acme Gateway, based on Ruralz" |
| Compatibility | Say a product, Plugin, Bundle or tool is "compatible with Ruralz" or "works with Ruralz" when it is true; Revington certifies nothing, so keeping the claim true is up to you | "Works with Ruralz 0.1 and later" |
| Plugins and integrations | Name them descriptively, with Ruralz after the word "for" | "Acme rate-limit Plugin for Ruralz" |
| Hosting | Say a service runs or hosts Ruralz when it does, as long as the service's own name does not contain Ruralz | "Acme Cloud offers hosted Ruralz" |

## Uses that need permission

- A modified build under the name Ruralz. Changed code or added or removed features make a different product: give it its own name, and say "based on Ruralz" if you like.
- A product, service, company, domain name, package name or social media account whose name contains Ruralz, other than the uses above.
- The Ruralz logo, except unaltered, to link to the project.
- Merchandise bearing the name or logo.
- Anything suggesting that Revington made, endorses, sponsors or certifies your product.

Ask Revington for permission through [revington.co](https://revington.co).

## Writing the name

- Spell it Ruralz, never RuralZ, and use the component names as they are: Ruralz Gateway (`ruralzd`), Ruralz Control (`ruralz-control`), Ruralz Console and the `ruralz` CLI.
- Use Ruralz as an adjective before what you mean, such as "the Ruralz Gateway" or "Ruralz Plugins", not as a verb or in the plural.
- In materials that use the name prominently, add once: "Ruralz is a trademark of Revington."
